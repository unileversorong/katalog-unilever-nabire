Cara upload manual (kalau publish otomatis gagal)

stock.json
  1. Buka repo GitHub katalog NABIRE di browser (repo ini HARUS beda dari repo kota lain).
  2. Klik Add file → Upload files.
  3. Seret (drag) file yang baru saja Anda download ke area upload itu. Nama file HARUS stock.json persis (akan menimpa file lama otomatis).
  4. Klik Commit changes.
  5. Tunggu ±1 menit sampai GitHub Pages selesai redeploy, lalu buka link katalog NABIRE untuk cek hasilnya.

ℹ️ Catatan

SKU yang TIDAK muncul sama sekali di kolom "Gudang Utama" pada file yang di-upload akan otomatis ditandai Stok Habis di katalog NABIRE. SKU yang muncul dengan stok Karton/Lusin/Pcs berapa pun (>0) akan ditandai Stok Tersedia (tampilan normal). File Excel diproses 100% di browser Anda — tidak dikirim ke server mana pun selain permintaan publish ke GitHub API di atas. Halaman admin ini HANYA memengaruhi katalog NABIRE — tidak ada koneksi apa pun ke repo/katalog kota lain.
